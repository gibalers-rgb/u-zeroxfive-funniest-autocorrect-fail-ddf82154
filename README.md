A program that writes one line under 200 characters that reads as a hilarious autocorrect fail. It keeps a shortlist of hand-written candidate fails, scores each against the judge's own rubric (clarity of the slip, surprise of the wrong word, realism as a genuine slip, originality of the wrong word), and writes the winner to `/output/entry.txt`. The winning line:

> Happy birthday! Hope your day is full of cake and peasants!

("presents" → "peasants": a birthday wish that accidentally invites the peasantry.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (59 characters, one line) and verifies it against the gate (1–199 characters, not only whitespace, single line) before exiting.
